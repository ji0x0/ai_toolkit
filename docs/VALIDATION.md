# 검증 범위와 현재 근거

## 이번 변경에서 실행한 검사

| 범위 | 목적 | 실제 결과 |
| --- | --- | --- |
| 도구 `python3 -m unittest discover -s tests -q` | 설치/참조·기록 보존·사본/복구·계약 검사·자동 세션 | 77개 통과 |
| 프런트 `npm test` | 계산/오류 문구 3건 + 실제 Vite HTTP 동작 5건 | 8개 통과, 실패/생략 0 |
| `npm run build` | TypeScript와 Vite 프로덕션 빌드 | 통과 |
| `python3 tools/validate.py` | 스킬 이름/frontmatter·로컬 참조·Python 구문 | 7개 스킬, 오류 0 |

도구와 프런트는 합계 85개다. 같은 사례의 재실행/부분집합을 새 검사로 더하지 않는다. 로컬 python3와 제공 Node를 사용했으며 CI 구성의 실행 결과와 구분한다.

## Vite 동작을 어떻게 확인했나

실제 Vite 개발/정적 미리보기 서버를 임시 로컬 포트에서 실행하고 Host 헤더를 바꿔 확인했다. 검사 후 서버와 임시 파일은 정리했다.

| 입력/조건 | 기대 결과 | 실제 결과 |
| --- | --- | --- |
| 외부 호스트 미지정, localhost 요청 | 로컬 접속 허용 | 200 |
| 외부 호스트 미지정, 임의 호스트 요청 | 차단 | 403, Blocked request |
| 명시한 복수 호스트 | 각각 접속 허용 | 200 |
| 허용 호스트 뒤에 다른 도메인을 붙인 요청 | 정확한 호스트와 다르므로 차단 | 403 |
| 정적 미리보기의 허용/미허용 호스트 | 개발 서버와 같은 정책 | 200 / 403 |
| 정적 미리보기의 /api 요청 | 격리된 mock upstream으로 전달 | 요청 경로/응답 일치 |
| 와일드카드·URL·포트 등 잘못된 설정 | 시작 전 명확한 오류 | 기대한 설정 오류 |
| 이미 사용 중인 포트 | 자동 포트 이동 없이 실패 | 기대한 포트 충돌 오류 |

코드는 [preview.test.mjs](../templates/frontend/tests/preview.test.mjs)와 [vite.config.ts](../templates/frontend/vite.config.ts)에 있다. 이는 Host/프록시/포트 검사이며 실제 제공 IDE의 TLS·HMR/WebSocket·경로 접두사·사용자 UI 전체를 확인한 결과는 아니다. 지정한 호스트의 신뢰성은 실제 환경에서 확인한다.

계산 검사는 [domain.test.mjs](../templates/frontend/src/domain.test.mjs)의 고정 입력/기대값 비교다. 합계/완료 수, 평균 부호와 막대 길이, 오류 문구 변환을 확인하며 HTTP·브라우저 화면 검사를 뜻하지 않는다.

## 설치/보존과 설명 지침

선택/전체 설치에서 새 참조 배포와 기존 업무 README·SERVICE·probe 보존을 확인한다. 설치 제한은 원본 참조와 설치 완료를 구분하며 EROFS/EACCES/EPERM은 테스트에서 주입한다. 실제 플랫폼 권한/마운트는 변경하지 않는다.

스킬 형식 검사·양식/참조 배포는 실제 에이전트가 모든 브리핑·기록·이해 절차를 지킨다는 행동 검증이 아니다. 변경 없는 이해 구간은 작업 지침이며 파일 쓰기를 차단하는 타이머가 아니다. 실제 사용자 이해/업무 효과는 해당 코드·실행·사용자 근거로 확인한다.

## 유지되는 기존 근거와 미실행

미변경 API 10개, 검색/생성 경계 7개, CSV/시계열 6개, ML 3개는 기존 로컬 통과 근거를 유지한다. 코드/의존성/입력·검사 명령이 달라지면 관련 검사를 다시 실행한다. 이 26개를 이번 실행 85개에 새로 합산하지 않는다.

컨테이너 실제 빌드/실행, 실제 제공 IDE의 UI, 외부 생성 모델 연결/정답률, 운영 부하·인증/조직 권한·복구는 이번 확인 범위 밖이다. CI에 검사/이미지 빌드 경로가 있다는 사실만으로 성공을 주장하지 않는다. 포함한 외부 원본의 라이선스/버전은 그대로 유지한다.
