### 아키텍처 다이어그램

아직 작성 전입니다. 실제 구성 요소와 데이터 방향을 확인한 뒤 Mermaid 다이어그램을 작성합니다.
계획 구성 요소는 현재 구현과 분리해 표시하고, 사용하지 않은 기술·외부 서비스를 넣지 않습니다.

### 대표 동작의 시퀀스·데이터 흐름

아직 작성 전입니다. 사용자 입력→컴포넌트→API/핵심 처리→저장/계산→응답/화면을 실제 흐름으로 설명합니다.
여러 부분을 오가는 동작은 시퀀스 또는 데이터 흐름 다이어그램도 작성합니다.
