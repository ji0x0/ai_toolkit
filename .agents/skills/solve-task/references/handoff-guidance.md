# 인계와 별도 검토 절차

현재 업무의 필수 산출물·실행 안내·검증 상태·저장 위치·미구현/미검증·사용자 영향을 확인한다. 자료 존재만으로 동작/이해 완료라고 하지 않는다. 확인한 코드/설정 버전과 현재 상태를 연결한다.

별도 검토/제출 단계가 있으면 실제 마감·파일 변경/문서 열람·도구 사용 조건을 확인한다. 과거 일정·절차·환경을 재사용하지 않는다. 제한되는 자동 작업은 전환 전에 최종 사본과 종료를 확인한다.

도구 지원이 허용되는 동안에는 입력 예측·코드 추적·선택 이유·실제 검증/AI 협업 근거·한계를 이해한다. 현재 단계에서 지원이 금지되면 그 범위의 작성을 중단한다. 일반 업무에 별도 제한을 임의로 추가하지 않는다.
