# 기존 최소 작업 기록 양식

현재 기본 정본은 사용자 요청에 따라 devlog.md와 probe.md다. 이 양식을 별도의 세 번째 정본으로 추가하지 않는다. 기존 과제가 한 문서만 허용할 때 아래 최소 항목을 두 구획에 맞춰 합치는 참고용으로 사용한다.

실제 요구한 파일이 있다면 그 안에 필요한 내용을 합친다. 다음 항목을 전부 별도 문서로 만들 필요는 없다.

## 목표와 근거

- 사용자/결정, 필수 결과물, 제한, 근거 위치
- 사실 / 가정 / 열린 질문 / 범위 밖

## 수용 기준

| ID | 입력·조건 | 기대 동작·출력 | 구현 위치 | 검증 근거·현재 상태 |
| --- | --- | --- | --- | --- |

## 실제 결정

시각 · 결정 · 비교한 대안 · 선택 이유 · 영향받는 요구

## 검증과 한계

명령/수동 절차 · 기대값 · 실제 결과 · 종료 코드/근거 위치 · 미검증 범위

## 이어서 할 일

현재 위치 · 다음 행동 · 실행 명령 · 진행 중인 서버 · 남은 오류/위험

‘예정’과 ‘실행 완료’를 구분한다. 존재하지 않는 인터뷰·실험·성능·작업 이력을 채우지 않는다.
